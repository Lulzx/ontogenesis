# M20 — Invent the Completed Object

## Required discovery

Given a toy zeta-like object with an awkward functional equation, M20 must
construct auxiliary factors so the new object has a maximally simple symmetry,
analogous to `Xi(s)=Xi(1-s)`. The completion may not be handed to the search.

## Status: reached — exact L3 toy completed object

M18 and M19 supplied the raw toy object and its signed reflection. M20 fixes a
bounded completion-factor grammar over exact rational power atoms and retains
`G(s)=C(p,s)^{-1}B'(p,s)`, where `B'(p,s)=p^{1-s}+1`. The completed object
`Ξ(s)=G(s)R(s)` satisfies the maximally simple symmetry `Ξ(1-s)=Ξ(s)` exactly.

On three frozen unseen prime sets the symmetry holds on all held-out
reflection pairs and operations fall 672→432. Asymmetric-universe and
corrupted-raw controls are declined; description falls 72→15 integers. M20
reaches `L3_transferred_ontology_with_measured_utility` as a bounded toy
completion. The raw-object definition, factor atoms, power primitive, and
exact checker remain supplied; no analytic completion or general normalization
is claimed.

## Evidence threshold

Candidate factors must be enumerated from a predeclared grammar, scored against
raw-equation complexity plus object complexity, validated off the fitting set,
and compared to trivial rescalings. The result must simplify several operations
or the total theory, not only make one displayed equation visually symmetric.
