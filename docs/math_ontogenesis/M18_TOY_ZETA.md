# M18 — Invent a Toy Zeta Function

## Required discovery

M18 seeks one compact analytic object connecting a global Dirichlet-like sum,
multiplicative factorization, special values, and zeros or poles in a controlled
arithmetic world.

## Status: not attempted

The necessary M17 arithmetic/factorization world has not been constructed.
The current formal-series object in M8 is one-variable and coefficient based;
it has no complex domain, analytic continuation, zeros, poles, or local Euler
factors.

## Completion evidence

A future object grammar must be fixed before observations are scored. The
winning object must jointly compress phenomena that were independently
available, generalize to held-out parameters, and beat separate models in
total description and reasoning cost. Naming a hand-designed finite zeta
function would not establish that the agent invented it.
